**Python Simple Calculator**
This project is a beginner-friendly command-line calculator built in Python. It demonstrates essential programming concepts such as function definitions, loops, and conditional logic.


**Troubleshooting and Fixes Made**
- ***Syntax Error***: Added a missing colon at the end of the function definition line for the add function.
- ***Indentation Error***: Fixed the indentation of the return statement within the add and divide functions to ensure correct code nesting.
- ***Variable Mismatch***: Corrected the parameter name in the multiply function from z to y to match the logic.
- ***Execution Guard***: Included the if "\_\_name_\_==\_\_main_\_\": block to prevent accidental function execution when imported as a module.


**Installation**
- Copy the code from cal.py into your preferred environment.
- Ensure you have Python installed.

**Usage**

Run the script directly from your terminal using python cal.py. Follow the prompts to choose an operation and enter your numbers.
